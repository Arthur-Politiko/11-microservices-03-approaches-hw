# Решение


## Задача 1: Обеспечить рахработку

Серверов будет несколько. 
**Self-hosted** будет отвечать за хранение docker образов, бэкап исходных кодов проекта, конфигурацию Terraform для Yandex cloud и необходимые инициализационные credentials 
**Облачный**. Весь CI/CD будет реализован в GitLab, это позволит остаться в одной инфраструктурк без танцев с бубном со сборкой франкенштейна. Credentials будут храниться в HashiCorp Vault, что позволит очень гибко работать с ACI и выдавать credentials только тем, кто в них нуждается. Артефакты будут храниться в GitLab - остаёмся в рамках одной среды. 

В облаке также будет развернута инфраструктура для тестирования. 


## Задача 2: Логи

Вместо ELK будет использоваться EVK (Elasticsearch, Vector, Kibana) или EFK (Elasticsearch, Fluent Bit, Kibana)
* Elasticsearch -> хранение и поиск
* Fluent Bit -> сбор логов
* Vector -> сбор логов
* Kibana -> UI

Logstash плохо уживается с Kubernetes да и тяжелыйй он, в этом отношении Fluent намного более легкий и нативный для Kubernetes.

Vector новее чем Fluent Bit, но чуть сложнее и не такой нативный для Kubernetes. Я бы остановился на Fluent Bit.

[Статья на Habr](https://habr.com/ru/articles/548998/)


## Задача 3: Мониторинг

Для мониторинга выберу стек Prometheus + Grafana, так как он:
* универсальный, обеспечивает сбор метрик как с хостов, так и с контейнеров и сервисов,
* поддерживает сбор пользовательских метрик через стандартный HTTP endpoint,
* предоставляет мощный язык запросов (PromQL) для анализа и агрегации,
* имеет гибкий интерфейс визуализации (Grafana) с настраиваемыми дашбордами,
* хорошо интегрируется в экосистенму с Kubernetes.
